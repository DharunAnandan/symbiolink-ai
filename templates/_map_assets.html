{# --------------------------------------------------------------------------- Leaflet + OpenStreetMap assets, shared by every map in the app (the registration picker, a company's location card, and the cluster overview). Pinned to an exact version rather than "latest" for the same reason dashboard.html pins Chart.js and matches.html pins vis-network: a silent major-version bump on a CDN should never be able to break a page. Leaflet's CSS must load before the map initialises -- without it the tiles are positioned as static images and the map renders as a broken stack of squares, which is the classic "my Leaflet map looks scrambled" symptom. No API key and no billing account: OpenStreetMap's tile server is open. That is also why the attribution below is not optional -- displaying it is a condition of the OSM tile usage policy, so it stays on every map. --------------------------------------------------------------------------- #}
