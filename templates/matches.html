Distances shown as “estimated” are straight-line (Euclidean) distances, used because no GOOGLE_MAPS_API_KEY is configured for this deployment (see .env.example) — the app already calls the Google Maps Distance Matrix API when a key is present, no code changes needed.

“Similar match” chains are found by the matching engine's semantic layer: materials with different names but a close enough textual/category match (e.g. “metal dust” and “metal shavings”) are surfaced as candidate opportunities the old exact-name-only matching would have missed entirely.

AI-rankedchains are scored by a trained model (logistic regression, learned from simulated accepted/declined outcomes) instead of a fixed hand-picked formula — each chain's reason line names the single learned factor driving its score. Falls back automatically to the original fixed-weight formula if the model hasn't been trained yet.
